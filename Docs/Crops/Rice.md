# 벼 (Rice)

벼 Species의 **단일 상세 문서**. 시스템 본문(`01_System.md`)에는 벼 수치·규칙을 중복하지 않고 여기로 링크한다.

| 항목 | 내용 |
|------|------|
| 표시 이름 | 벼 |
| 티어 | 1 |
| 한 줄 설명 | 프로토타입 기본 Species. 성장 속도·드랍률 스탯. |
| 프로토 역할 | 현재 **교배 부모 Species** (프로토타입). 플레이 중심 Species. |

양식: `00_CropFormat.md`. 시스템 공통 규칙: `01_System.md`.

### 스탯

| 스탯 이름 | 범위 | 효과 |
|-----------|------|------|
| 성장 속도 | 0 ~ 5 | Mature까지 필요 틱 단축 (아래 공식) |
| 드랍률 | 0 ~ 5 | 효과 미정 (`01_System_tofill` S28) |

상속·클램프: 각 스탯 **0~5**.

### 성장

공통 기본: 최저 **60초** → 최고 **10초**, 단계 **3** — `00_CropFormat.md`.

| 항목 | 내용 |
|------|------|
| 기본 Mature 틱 (성장 속도 0) | 1200틱 (60초) |
| 성장 공식 | `growTimeTicks = 1200 - 200 * 성장속도` |
| 단계 수 | 3 |

성장 속도 1당 **200틱(10초)** 감소.

| 성장 속도 | Mature 틱 | 환산 초 |
|-----------|-----------|---------|
| 0 | 1200 | 60 |
| 5 | 200 | 10 |

#### 성장 단계

| 단계 | 조건 (progress) | 의미 |
|------|-----------------|------|
| 0 | 0% ~ 19% | 시작 |
| 1 | 20% ~ 99% | 자라는 중 |
| 2 | 100% | 다 자람 (Mature, 수확 가능) |

비료 성장 보너스(스탯 독립)는 `01_System.md` §5.5 / 프로토 가정 −40틱.

### 수확

| 항목 | 내용 |
|------|------|
| 산출물 | 벼(작물) × **1** |
| 칸 잔류 | **남김** — 성장만 리셋, 같은 스탯으로 다시 자람 |
| 판매 가격 | **10골드** / 벼(작물) |
| 기타 | 씨앗은 칸에 잔류. 드랍률은 수량에 아직 미반영 (S28) |

### 시작 · 심기

| 항목 | 내용 |
|------|------|
| 시작 지급 | 벼 씨앗 **1개** |
| 시작 스탯 | 성장 속도 **0** / 드랍률 **0** |
| 심기 조건 | **빈 칸만**, 씨앗 1개 소비 |

### 씨앗 · 경제

| 항목 | 내용 |
|------|------|
| 상점 구매 | **가능**. 스탯 **0/0**(성장0·드랍0)만. **개당 20골드** |
| 상점 판매 (씨앗) | **불가** (스탯 붙은 씨앗 포함 언제나 판매 불가) |
| 상점 판매 (작물) | 벼(작물) **10골드**/개 |

### 교배 · 변종

| 항목 | 내용 |
|------|------|
| 프로토타입 교배 | **가능** — 교접 지지대, 부모 ≥1, 상하좌우. 프로토에서 부모 Species는 **벼만** |
| 변종 풀 | 교배 시 20% 풀 롤 — **규칙만, 미구현** (`01_System.md` §5.2) |

**유전자 풀 (확정)** — 벼 교배 결과에 포함:

| 결과 | 문서 |
|------|------|
| 감자 | `Potato.md` |
| 당근 | `Carrot.md` |

풀 가중치·동종 벼 잔류 비율·등장 시 스탯: tofill R01.  
상속: `자식 = 부모평균 + RandomInt(-2,4)` → **0~5** 클램프. 비료 하한은 `01_System.md` §5.5.  
(풀로 나온 감자·당근은 해당 Species 범위로 클램프.)
