# 향료초 (Spiceleaf)

교역(D1) **후기** 전용 Species 설계. 로컬 Unity `Docs/Crops/`에는 아직 없음 — Project store 초안.  
양식: 로컬 `00_CropFormat.md`. 시스템: `01_System.md`. 교역: `../01_trade-system.md`.

| 항목 | 내용 |
|------|------|
| 표시 이름 | 향료초 |
| 티어 | 3 `(가정)` |
| 한 줄 설명 | 희귀도 기반 소량·고보상 교역종. 콩과 비슷하게 **발견·교차** 맛이 강함. |
| 모듈 | D1 교역 |

역할: 대량(면화·감자)과 대비되는 **희소 납품**. 상점 판매가도 있으나, 주 가치는 특약 주문.  
콩(상품성=가격)과 차별: 향료초는 **희귀도→교역 배율**, 상점가는 완만 `(가정)`.

### 스탯

| 스탯 이름 | 범위 | 효과 |
|-----------|------|------|
| 성장 속도 | 0 ~ 10 | Mature까지 필요 틱 단축 |
| 희귀도 | 0 ~ 20 | 교역 납품 시 **보상 배율**; 상점 판매 가산 (아래) |

상속·클램프: 성장 0~10, 희귀도 0~20.  
새 키는 부모에 없으면 **0**.

### 성장

콩보다 짧고, 전 작물 기본보다 약간 김 `(가정)`.

| 항목 | 내용 |
|------|------|
| 기본 Mature 틱 (성장 속도 0) | **2400틱 (120초 / 2분)** |
| Mature 틱 (성장 속도 10) | **400틱 (20초)** |
| 성장 공식 | `growTimeTicks = 2400 - 200 * 성장속도` |
| 단계 수 | 3 (공통) |

| 성장 속도 | Mature 틱 | 환산 |
|-----------|-----------|------|
| 0 | 2400 | 2분 |
| 10 | 400 | 20초 |

#### 성장 단계

| 단계 | 조건 (progress) | 의미 |
|------|-----------------|------|
| 0 | 0% ~ 19% | 시작 |
| 1 | 20% ~ 99% | 자라는 중 |
| 2 | 100% | Mature |

비료: `01_System.md` §5.5.

### 수확

| 항목 | 내용 |
|------|------|
| 산출물 | 향료초(작물) × **1** `(가정)` |
| 칸 잔류 | **남김** `(가정)` |
| 판매 가격 | **8 + floor(희귀도 / 2)** 골드/개 `(가정)` — 희귀 0→8G, 20→18G |
| 기타 | 교역 특약 주문 시 `보상 × (1 + 희귀도/40)` 배율 `(가정)` — 희귀 20 ≈ ×1.5 |

대량 납품용이 아님. 주문 수량은 보통 **1~3**.
