# 감자 (Potato)

| 항목 | 내용 |
|------|------|
| 표시 이름 | 감자 |
| 티어 | 1 |
| 한 줄 설명 | 저가·다수확 Species. 성장 속도·드랍률 0~15. |

양식: `00_CropFormat.md`. 시스템 공통 규칙: `01_System.md`.

### 스탯

| 스탯 이름 | 범위 | 효과 |
|-----------|------|------|
| 성장 속도 | 0 ~ 15 | Mature까지 필요 틱 단축 (아래 공식) |
| 드랍률 | 0 ~ 15 | 수확 시 **감자(작물) 수량** (아래 공식) |

### 성장

공통 기본(전 작물): **최저 60초(1200틱) → 최고 10초(200틱)**, **단계 3** — `00_CropFormat.md`.

| 항목 | 내용 |
|------|------|
| 기본 Mature 틱 (성장 속도 0) | 1200틱 (60초) |
| 성장 공식 | `growTimeTicks = 1200 - (1000 * 성장속도) / 15` |
| 단계 수 | 3 |

| 성장 속도 | Mature 틱 | 환산 초 |
|-----------|-----------|---------|
| 0 | 1200 | 60 |
| 15 | 200 | 10 |

#### 성장 단계

| 단계 | 조건 (progress) | 의미 |
|------|-----------------|------|
| 0 | 0% ~ 19% | 시작 |
| 1 | 20% ~ 99% | 자라는 중 |
| 2 | 100% | 다 자람 (Mature, 수확 가능) |

비료 성장 보너스(스탯 독립)는 `01_System.md` §5.5.

### 수확

| 항목 | 내용 |
|------|------|
| 산출물 | 감자(작물) × **드랍률 수량** (벼보다 많이 나옴) |
| 칸 잔류 | 미정 |
| 판매 가격 | **5골드** / 감자(작물) |
| 기타 | 드랍률 0 → **1개**. 드랍률 15(최대) → **4~5개** |

**드랍률 → 수량**

```
lo = 1 + floor(드랍률 * 3 / 15)
hi = 1 + floor(드랍률 * 4 / 15)
수량 = RandomInt(lo, hi)   // 양끝 포함
```

| 드랍률 | lo ~ hi |
|--------|---------|
| 0 | 1 ~ 1 |
| 15 | 4 ~ 5 |

벼(고정 1개·10G) 대비: 개당 값은 낮고, 드랍률로 수량을 늘리는 타입.
