# 콩 (Bean)

| 항목 | 내용 |
|------|------|
| 표시 이름 | 콩 |
| 티어 | 미정 |
| 한 줄 설명 | 상품성 기반 고가 Species. 감자×당근 교배로만 해금. |

양식: `00_CropFormat.md`. 시스템 공통 규칙: `01_System.md`.

역할: 판매가가 **상품성 스탯에 직결**. 상점 온램프 없음 — 교배 발견 전용.

### 스탯

| 스탯 이름 | 범위 | 효과 |
|-----------|------|------|
| 성장 속도 | 0 ~ 10 | Mature까지 필요 틱 단축 (아래 공식) |
| 상품성 | 0 ~ 50 | 작물 **판매 골드** = 상품성 수치 |

### 성장

**예외**: 전 작물 기본(60초→10초)이 아님. 콩은 더 김.

| 항목 | 내용 |
|------|------|
| 기본 Mature 틱 (성장 속도 0) | **3600틱 (180초 / 3분)** |
| Mature 틱 (성장 속도 10) | **600틱 (30초)** |
| 성장 공식 | `growTimeTicks = 3600 - 300 * 성장속도` |
| 단계 수 | 3 (공통) |

성장 속도 1당 **300틱(15초)** 감소.

| 성장 속도 | Mature 틱 | 환산 |
|-----------|-----------|------|
| 0 | 3600 | 3분 |
| 10 | 600 | 30초 |

#### 성장 단계

| 단계 | 조건 (progress) | 의미 |
|------|-----------------|------|
| 0 | 0% ~ 19% | 시작 |
| 1 | 20% ~ 99% | 자라는 중 |
| 2 | 100% | 다 자람 (Mature, 수확 가능) |

비료 성장 보너스(스탯 독립)는 `01_System.md` §5.5.

### 수확

| 항목 | 내용 |
|------|------|
| 산출물 | 콩(작물) × 1 `(가정)` |
| 칸 잔류 | 미정 (tofill B01) |
| 판매 가격 | **상품성 골드**/개 — 상품성 0 → **0G**, 50 → **50G** |
| 기타 | `판매가 = 상품성` (1:1) |

### 씨앗 획득

| 경로 | 내용 |
|------|------|
| 감자+당근 교배 | **유일한 경로**. 부모에 감자·당근이 함께 참여한 교배에서 등장 (`01_System.md` §5.2) |
| 상점 구매 | **불가** |
| 벼 유전자 풀 | **없음** |
| 시작 지급 | **없음** |

등장 확률·필요 부모 조합 세부: tofill B01.

### 시작 · 심기

| 항목 | 내용 |
|------|------|
| 시작 지급 | **없음** |
| 시작 스탯 | 교배 등장 시 — tofill B01 (제안: 성장0·상품성0) |
| 심기 조건 | **빈 칸만**, 씨앗 1개 소비 (공통) |

### 씨앗 거래

| 항목 | 내용 |
|------|------|
| 상점 구매 | **불가** |
| 상점 판매 | **불가** (공통) |

### 교배 · 변종

| 항목 | 내용 |
|------|------|
| 해금 조건 | **감자 + 당근** 교배식 (`Potato.md` / `Carrot.md`) |
| 스탯 상속 | 부모와 키 공유 시 상속, **상품성**은 부모에 없으면 **0**에서 시작 (`01_System.md` §5.2) |
| 클램프 | 성장 0~10, 상품성 0~50 |

비료 하한은 `01_System.md` §5.5. 하한 캡이 상품성(최대 50)에 어떻게 적용되는지는 tofill F03·B01.
