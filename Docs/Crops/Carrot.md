# 당근 (Carrot)

| 항목 | 내용 |
|------|------|
| 표시 이름 | 당근 |
| 티어 | 미정 |
| 한 줄 설명 | 빠른 사이클 Species. 교배·번식 가속용. |

양식: `00_CropFormat.md`. 시스템 공통 규칙: `01_System.md`.

역할: Mature가 짧아 **심기→수확→재교배** 루프를 자주 돌릴 수 있음. 개당 판매가는 감자와 같고, 가치는 **회전 속도**.

### 스탯

감자(`Potato.md`)와 **동일 제한**.

| 스탯 이름 | 범위 | 효과 |
|-----------|------|------|
| 성장 속도 | 0 ~ 15 | Mature까지 필요 틱 단축 (아래 공식) |
| 드랍률 | 0 ~ 15 | 효과 미정 (tofill C01) |

### 성장

**예외**: 전 작물 기본(60초→10초)이 아님. 당근은 더 빠름.

| 항목 | 내용 |
|------|------|
| 기본 Mature 틱 (성장 속도 0) | **400틱 (20초)** |
| Mature 틱 (성장 속도 15) | **100틱 (5초)** |
| 성장 공식 | `growTimeTicks = 400 - (300 * 성장속도) / 15` |
| 단계 수 | 3 (공통) |

| 성장 속도 | Mature 틱 | 환산 초 |
|-----------|-----------|---------|
| 0 | 400 | 20 |
| 15 | 100 | 5 |

#### 성장 단계

| 단계 | 조건 (progress) | 의미 |
|------|-----------------|------|
| 0 | 0% ~ 19% | 시작 |
| 1 | 20% ~ 99% | 자라는 중 |
| 2 | 100% | 다 자람 (Mature, 수확 가능) |

비료 성장 보너스(스탯 독립)는 `01_System.md` §5.5.

### 수확

| 항목 | 내용 |
|------|------|

### 씨앗 획득

| 경로 | 내용 |
|------|------|
| 벼 유전자 풀 | **벼(쌀)** 교배 변종 풀에 포함 (`Rice.md`, `01_System.md` §5.2) |
| 상점 구매 | **가능** (기본 스탯·가격 → tofill C01) |
| 시작 지급 | **없음** |

### 시작 · 심기

| 항목 | 내용 |
|------|------|
| 시작 지급 | **없음** |
| 시작 스탯 | 상점·풀 등장 시 — tofill C01 |
| 심기 조건 | **빈 칸만**, 씨앗 1개 소비 (공통) |

### 씨앗 거래

| 항목 | 내용 |
|------|------|
| 상점 구매 | **가능** (이중 경로). 스탯·개당 골드: tofill C01 |
| 상점 판매 | **불가** (공통) |

### 교배 · 변종

| 항목 | 내용 |
|------|------|
| 풀 출처 | **벼**의 유전자 풀 멤버 |
| 설계 의도 | 짧은 Mature로 교배/번식 시도 횟수를 늘림 |
| 교차 | **감자와 함께** 부모로 참여한 교배 → **콩** 가능 (`Bean.md`) |
| 변종 롤 | 규칙만, 미구현 (`01_System.md` §5.2) |

상속·클램프는 Species 범위(0~15). 비료 하한은 `01_System.md` §5.5.
