# 면화 (Cotton)

교역(D1) **2차** 전용 Species 설계. 로컬 Unity `Docs/Crops/`에는 아직 없음 — Project store 초안.  
양식: 로컬 `00_CropFormat.md`. 시스템: `01_System.md`. 교역: `../01_trade-system.md`.

| 항목 | 내용 |
|------|------|
| 표시 이름 | 면화 |
| 티어 | 2 `(가정)` |
| 한 줄 설명 | 섬유량 기반 교역종. 생판매보다 **직물·대량 납품**에 가치. |
| 모듈 | D1 교역 |

역할: 감자처럼 **수량**을 맞추되, 상점 시세는 낮고 **교역 주문 보상**이 주 수익. Mill 인풋 아님 `(가정)`.

### 스탯

| 스탯 이름 | 범위 | 효과 |
|-----------|------|------|
| 성장 속도 | 0 ~ 8 | Mature까지 필요 틱 단축 |
| 섬유량 | 0 ~ 12 | 수확 **면화(작물) 수량** (아래 공식) |

상속·클램프: 성장 0~8, 섬유량 0~12.  
부모에 섬유량 키 없으면 **0**에서 시작 (`01_System` §5.2).

### 성장

공통 기본(60초→10초) 사용 — `00_CropFormat.md`.

| 항목 | 내용 |
|------|------|
| 기본 Mature 틱 (성장 속도 0) | 1200틱 (60초) |
| Mature 틱 (성장 속도 8) | 200틱 (10초) |
| 성장 공식 | `growTimeTicks = 1200 - (1000 * 성장속도) / 8` |
| 단계 수 | 3 |

| 성장 속도 | Mature 틱 | 환산 초 |
|-----------|-----------|---------|
| 0 | 1200 | 60 |
| 8 | 200 | 10 |

#### 성장 단계

| 단계 | 조건 (progress) | 의미 |
|------|-----------------|------|
| 0 | 0% ~ 19% | 시작 |
| 1 | 20% ~ 99% | 자라는 중 |
| 2 | 100% | Mature |

비료 성장 보너스(스탯 독립): `01_System.md` §5.5.

### 수확

| 항목 | 내용 |
|------|------|
| 산출물 | 면화(작물) × **섬유량 수량** |
| 칸 잔류 | **남김** `(가정)` — 벼와 동일, 성장만 리셋 |
| 판매 가격 | **3골드**/개 — 상점 즉시 판매는 손해에 가깝게 `(가정)` |
| 기타 | 교역 「직물·면화」 주문의 주 원료 |

**섬유량 → 수량** `(가정)`

```
lo = 1 + floor(섬유량 * 2 / 12)
hi = 1 + floor(섬유량 * 3 / 12)
수량 = RandomInt(lo, hi)   // 양끝 포함
```

| 섬유량 | lo ~ hi |
|--------|---------|
| 0 | 1 ~ 1 |
| 12 | 3 ~ 4 |

감자(최대 4~5, 개당 5G)보다 개당 상점가는 낮고, **교역 납품 단가**로 보상 `(가정)`.

### 씨앗 획득

| 경로 | 내용 |
|------|------|
| 상점 구매 | **가능** — 평판 티어 「상인」(≥25) 해금 후 `(가정, T11)` |
| 벼 유전자 풀 | **없음** (교역 전용 온램프) |
| 시작 지급 | **없음** |
| 교차 | 1차 불필요. `(가정)` 후기: 감자×면화 등 |

### 시작 · 심기

| 항목 | 내용 |
|------|------|
| 시작 지급 | 없음 |
| 시작 스탯 | 상점 구매 시 성장 **0** / 섬유량 **0** `(가정)` |
| 심기 조건 | 빈 칸만, 씨앗 1개 소비 (공통) |

### 씨앗 거래

| 항목 | 내용 |
|------|------|
| 상점 구매 | 가능. **개당 35골드**, 스탯 0/0만 `(가정, T11)` |
| 상점 판매 | **불가** (공통) |

### 교배 · 변종

| 항목 | 내용 |
|------|------|
| 프로토타입 교배 | 로컬 프로토는 벼만 — 면화 교배는 **교역 2차+** `(가정)` |
