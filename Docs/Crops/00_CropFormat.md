# 작물 문서 양식

`Docs/Crops/` 아래 개별 작물 `.md`는 이 양식을 따른다.

## 공통 규칙

- Species마다 **스탯 스키마가 다름** (`01_System.md` §2).
- 시간 단위: **틱**. **1초 = 20틱** (`01_System.md` §0.1).

### 전 작물 기본 (확정)

작물 문서에 달리 쓰지 않으면 아래를 따른다.

| 항목 | 기본 |
|------|------|
| 성장 단계 수 | **3** |
| 단계 구간 | 0: 0~19% / 1: 20~99% / 2: 100%(Mature) |
| Mature 틱 (성장 속도 **최저**) | **1200틱 (60초)** |
| Mature 틱 (성장 속도 **최고**) | **200틱 (10초)** |
| 성장 공식 | 최저~최고를 스탯 범위에 **선형** 보간 |
| 심기 | **빈 칸만**, 씨앗 1개 소비 |
| 씨앗 상점 판매 | **불가** |

`progress = elapsedTicks / growTimeTicks` (0~1). 비료 성장 보너스는 스탯과 독립 (`01_System.md` §5.5).

선형 보간 예:

```
growTimeTicks = 1200 - (1000 * (성장속도 - min)) / (max - min)
```

`성장속도 = min` → 1200, `= max` → 200.
