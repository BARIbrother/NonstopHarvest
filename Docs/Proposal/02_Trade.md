# 01. 교역 시스템 (D1)

밭 상점의 즉시 판매와 별도로, **외부 주문에 맞춰 심고·비축하고·납품**하는 콘텐츠 방향.

확정 아닌 내용은 `(가정)`. 구현 차단 미결은 `01_trade-system_tofill.md`.  
기반: 로컬 `Docs/Crops`(벼·감자·당근·콩), `Docs/Machine/Mill.md`, `Docs/Proposal/01_System.md` §5.4~5.7.  
UI: `02_trade-ui.md` + Canvas.

---

## 0. 한 줄 컨셉

**주문 보드 → 재배/비축 → 납품 → 골드·평판 → 더 큰 주문.**  
기존 육종·Mill 비료 루프는 그대로 두고, “무엇을 심을지”에 **시한 있는 외부 수요**를 얹는다.

---

## 1. 기존 시스템과의 연결

| 기존 | 교역에서의 역할 |
|------|-----------------|
| 상점 구매\|판매 (`01_System` §5.7) | 즉시 판매는 유지. 교역은 **별 채널**(주문 납품). 씨앗·Mill·지지대 구매는 그대로 |
| 벼 10G / 감자·당근 5G / 콩=상품성 | 주문 보상은 **상점 시세보다 유리** `(가정)` — 시한이 리스크 |
| 인벤(작물·씨앗) | 납품 시 작물 스택에서 차감 |
| Mill (벼→비료) | 납품 아이템이 아님. **납품용 작물 육종·성장**을 돕는 기반 |
| 교접·해금 (벼→감자·당근→콩) | 주문 풀이 Species 해금에 따라 넓어짐 |
| 5×5·퀵슬롯·맨손 | 재배는 기존 조작. 교역 UI만 추가 |

**충돌 방지**

- 씨앗 판매 불가 규칙 유지 — 납품 대상은 **작물(수확물)** 만 `(가정)`.
- 동일 스택을 상점 판매와 교역 납품에 쓸 수 있음 — 플레이어 선택.

---

## 2. 해금 → 주문 → 납품 → 보상 전체 라인

```
[해금] 첫 벼 작물 판매 1회 또는 누적 골드 ≥ 30  (가정, T01)
   ↓
[진입] 상점 「교역」 탭 해금  (가정: 1차 슬라이스 = 건물 없이 탭)
   ↓
[보드] 활성 주문 슬롯 표시 (기본 3, 가정 T02)
   ↓
[수락] 주문 1건 수락 → 「진행 중」 (동시 진행 상한 가정 T03)
   ↓
[재배·비축] 밭에서 해당 Species 심기·수확·인벤 비축
           (선택) Mill→비료→성장/교접으로 납품 준비 가속
   ↓
[납품] 교역 UI에서 보유량만큼 제출 (부분 납품 허용 여부 = T04)
   ↓
[정산] 골드 + 평판. 실패/만료 시 평판만↓ 또는 무페널티 (T05)
   ↓
[갱신] 슬롯 비면 새 주문 후보 채움. 평판 티어↑ 시 고가·교역종 주문 등장
```

### 2.1 해금 `(가정)`

| 항목 | 내용 |
|------|------|
| 조건 | 벼(작물) **상점 판매 1회** 또는 보유 골드 **≥ 30** 중 빠른 쪽 |
| 결과 | 상점 상단에 **구매 \| 판매 \| 교역** 탭. 교역 탭 = 주문 보드 |
| 안내 | 첫 해금 시 튜토리얼 주문 1건(벼×3, 넉넉한 시한) 고정 등장 |

1차 슬라이스에는 **Trade Post 건물 없음** (플랜 CD-D1-02 기본 제안과 동일). 2차에서 교역소 1×1 배치 가능 `(가정)`.

### 2.2 주문 보드

| 필드 | 설명 |
|------|------|
| 주문 ID | 내부 |
| 의뢰 표시명 | 예: 「마을 식량」「직물 길드」 `(가정)` 플레이버 |
| 요구 | Species + 수량 (작물 단위) |
| 보상 골드 | 고정 또는 시세×배율 `(가정)` |
| 평판 | 성공/실패 시 증감 |
| 시한 | 수락 후 **틱** 카운트다운 (1초=20틱) |
| 최소 평판 | 이 주문 노출에 필요한 평판 `(가정)` |
| 상태 | 대기 / 진행 / 완료 / 만료 / 거절 |

**슬롯 `(가정)`**: 보드에 **대기 후보 3**, 동시 **진행 2**.  
거절 가능 — 거절 시 그 슬롯만 즉시 교체, 평판 변화 없음 `(가정)`.

### 2.3 주문 생성 규칙 `(가정)`

해금된 Species만 요구 풀에 넣는다.

| 해금 상태 | 주문 풀 |
|-----------|---------|
| 벼만 | 벼 소량·중량 |
| +감자 | 감자 대량(다수확 특화), 벼+감자 혼합 |
| +당근 | 당근 단기(빠른 사이클), 혼합 |
| +콩 | 콩 소량 고가 (상품성 높은 콩일수록 보너스 T06) |
| +면화·향료초 | 교역 전용 주문 (직물·향신 납품) |

가중치·정확한 수량 밴드: tofill T07.

### 2.4 재배·비축 (플레이)

1. 주문 요구 Species 확인 → 씨앗 확보(상점/풀/교차).
2. 밭 심기 → (선택) 비료·교접으로 납품량·품질 준비.
3. 수확물을 인벤에 쌓음. **상점 즉시 판매 vs 교역 비축** 선택.
4. Mill은 벼를 비료로 바꿔 **다음 사이클 준비**에 씀. 주문에 비료 납품 없음 `(가정)`.

### 2.5 납품

| 항목 | 내용 |
|------|------|
| 진입 | 교역 탭 → 진행 중 주문 → 「납품」 |
| 입력 | 보유 작물 중 요구 Species 수량 지정 (슬라이더/±) |
| 소비 | 확인 시 인벤에서 즉시 차감 |
| 부분 납품 | `(가정)` **허용**. 요구량 채우면 자동 완료 |
| 초과 | 요구량까지만 받음 |

콩 주문 `(가정)`: 요구가 「콩×N」이면 **개수**만 봄. 상품성 합산 보너스는 T06.

### 2.6 보상 · 평판 · 다음 주문

| 결과 | 골드 | 평판 `(가정)` |
|------|------|---------------|
| 성공(요구량 충족) | 주문 표기액 | +1 ~ +3 (티어·난이도) |
| 만료(시한 0) | 0 | −1 (또는 0, T05) |
| 자진 포기 | 0 | 0 |

**평판 티어 `(가정)`**

| 평판 | 티어 | 효과 |
|------|------|------|
| 0 ~ 9 | 견습 | 기본 주문만 |
| 10 ~ 24 | 단골 | 보상 ×1.1, 혼합 주문↑ |
| 25 ~ 49 | 상인 | 면화 주문·씨앗 상점 해금 |
| 50+ | 특약 | 향료초 주문·교차 힌트 |

티어 경계·배율: tofill T08.

성공/만료 후 해당 진행 슬롯 비움 → 대기 후보에서 채우거나 새로 롤.

## 3. 기반 작물 역할 (납품 메타)

| Species | 교역 역할 | 근거(로컬 문서) |
|---------|-----------|-----------------|
| **벼** | 초반·안정 납품. 튜토리얼 주문 | 판매 10G, Mill 원료, 시작종 |
| **감자** | **대량** 주문. 드랍률로 수량 맞춤 | 5G, 드랍 0→1 / 15→4~5개 |
| **당근** | **단기·반복** 주문. 시한 촉박 주문에 유리 | Mature 20→5초 |
| **콩** | **고가·소량**. 평판 중후반 주문 | 상품성=판매가, 교차 해금 |

Mill: 납품 직전 벼를 갈지 말고, **남는 벼 → 비료 → 감자/당근/교역종 육성**이 권장 플레이 `(가정)`.

## 6. 경제 스케치 `(가정)` — 단정 아님, 밸런스 tofill

벼 상점 10G 대비 교역은 **약 1.2~1.5× 시세**에 시한 리스크.  
예: 벼×5 주문 보상 70G (상점 50G 대비 +40%), 시한 약 3~5분(3600~6000틱).

정확한 표: T07·T09.

---

## 7. 프로토타입 / 1차 구현 범위 `(가정)`

**포함**

- 해금 → 교역 탭 → 보드 3슬롯
- 기반 작물(벼·감자·당근·콩) 주문만
- 수락·납품·골드 보상·단순 평판(+1/성공)
- 시한(틱)

**제외**

- Trade Post / Packer
- 면화·향료초 (문서만, 2차)
- 평판 티어별 배율·플레이버 NPC
- 부분 납품 UX 고도화 (1차는 전량만 허용 가능 — T04)
