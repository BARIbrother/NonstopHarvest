# 01. 게임 시스템

## 0. 한 줄 컨셉

Gregtech: New Horizons의 **cropsNH** 루프만 떼어, **교배·스탯·티어 상승이 도파민 보상**이 되는 농사 게임.

레퍼런스: IC2 crops / GTNH cropsNH (교배·육종 루프).  
**차이**: cropsNH처럼 전 작물 공통 G/G/R이 아니라, **작물 종류(Species)마다 스탯 구성이 다름**.

확정 아닌 가정은 `(가정)`. 미결은 `01_System_tofill.md`.

---

## 0.1 시간 단위 (틱)

- **확정**: 게임 내부 시간은 **틱** 기준.
- **확정**: **1초 = 20틱**.
- 성장·기계 가공 등 진행은 틱으로 표기·계산. (필요 시 초 환산은 `/20`)

---

## 1. 핵심 루프

```
심기 → 성장 → (선택) 교배/변종 → 수확 → 스탯 좋은 씨앗 확보 → 재투자
```

도파민 포인트 (목표 체감):

| 순간 | 보상 감각 |
|------|-----------|
| 스탯 상승 | 숫자 올라감 |
| 변종·신종 | 발견·잭팟 |
| 밭 확장·자동화 | 규모 쾌감 |

프로토타입 최소 루프: **심기 → 성장 → 수확 → 씨앗 스탯 확인 → 재파종**.

---

## 2. 작물 인스턴스 · 스탯 모델

밭 한 칸에 작물 하나.

| 필드 | 설명 |
|------|------|
| Species | 작물 종류. **스탯 스키마를 정의** |
| Stats | Species별 스탯 맵 (종류·범위가 Species마다 다름) |
| 성장 진행 | 틱 경과 → Mature |
| Mature | 수확 가능 여부 |

### 2.1 프로토타입 Species: 벼

| 스탯 | 범위 | 효과 |
|------|------|------|
| 성장 속도 | 0 ~ 5 | Mature까지 틱 단축 (§3) |
| 드랍률 | 0 ~ 5 | 효과 미정 (§4, tofill) |

---

## 3. 성장

- **확정**: 성장은 **틱**으로 진행 (1초 = 20틱).
- **확정 (벼)**: Mature까지 필요 틱, 성장 속도에 **선형**.

| 성장 속도 | Mature 틱 | (환산 초) |
|-----------|-----------|-----------|
| 0 | 600틱 | 30초 |
| 5 | 200틱 | 10초 |

공식:

```
growTimeTicks = 600 - 80 * 성장속도
```

(`성장속도` 1당 80틱 = 4초 감소.)

- **확정**: **비료 성장 보너스**는 작물 스탯(성장 속도)과 **독립**으로 추가로 적용 (§5.5). 최종 성장 시간 계산 시 스탯 공식 결과에 보너스를 더한다.

### 3.1 성장 단계

- **확정**: 단계 수는 **작물(Species)마다 다름**.
- **확정 (벼)**: 3단계. `progress = elapsedTicks / growTimeTicks` (0~1).

| 단계 | 조건 | 의미 |
|------|------|------|
| 0 | progress 0% ~ 19% | 시작 |
| 1 | progress 20% ~ 99% | 자라는 중 |
| 2 | progress 100% | 다 자람 (Mature, 수확 가능) |

`(가정)` 환경(양분·습도·공기)은 프로토타입에서 생략.

---

## 4. 심기 · 수확 · 씨앗

### 4.1 시작 · 심기

- **확정**: 게임 시작 시 **벼 씨앗 1개**.
- **확정**: 시작 스탯 **성장 속도 0 / 드랍률 0**.
- **확정**: **빈 칸에만** 심기 가능. 씨앗 1개 소비 → 해당 스탯 작물 배치.

### 4.2 수확 · 드랍률

- **확정**: Mature(단계 2) 수확 시 **벼(작물)** 획득.
- **확정**: **원래 칸의 작물(씨앗)은 남김** — 칸 비우지 않고 성장만 리셋(같은 스탯으로 다시 자람).
- 벼(작물) = 판매용 (§5.4). 다른 칸에 심을 인벤 씨앗은 시작 지급·교배 등으로.
- **드랍률** 스탯 효과: 미정 (`01_System_tofill`). 예전 확률식은 폐기.

---

## 5. 교배 · 변종 · 경제

### 5.1 교접 지지대 (프로토타입 포함)

- **확정**: 프로토타입에 **교배 넣음**.
- **확정**: 빈 칸에 **식물 교접 지지대**를 놓으면(소비), 그 칸의 **상·하·좌·우 4칸** 작물이 **부모**.
- **확정**: 부모 **≥ 1**이면 진행.
- **확정**: 자식은 **지지대 칸에서 새 작물로 성장** (스탯 §5.3).
- **확정**: 지지대는 **소비 아이템**. 시작 **10개** 지급. 상점에서 **5골드**에 구매.
- **확정**: 프로토타입 부모 Species는 **벼만**.
- 변종 20% 롤은 §5.2 (프로토타입 미구현).

### 5.2 변종 (유전자 풀)

- 교배 시 **20%** 확률로 유전자 풀에서 **변종** 등장.
- **확정**: 이 변종 롤은 **현재 프로토타입에서 구현하지 않음** (규칙만 문서화).
- 변종 스탯: 부모와 **같은 스탯 키** → 상속. **새 스탯** → **0**.

### 5.3 상속 공식

```
자식스탯 = 부모스탯평균 + RandomInt(-2, 4)
```

- `부모스탯평균`: 상하좌우 부모(1~4)의 해당 스탯 평균.
- `RandomInt(-2, 4)`: -2 이상 4 이하 정수 균등.
- `(가정)` 결과는 Species 스탯 범위로 클램프 (벼면 각 스탯 0~5).
- 비료가 적용된 교접이면 §5.5 하한 규칙 추가 적용.

### 5.4 경제 (골드)

| 항목 | 가격 |
|------|------|
| 벼(작물) 판매 | **10골드** |
| 식물 교접 지지대 구매 | **5골드** |
| 비료 뿌리개 (첫 비료 후 해금) | **0골드** |

- **확정**: 시작 골드 **0**.
- **확정**: **씨앗 판매 불가** (작물만 판매).

### 5.5 비료

출처: Mill이 작물을 가공해 **비료** 생산 (`Docs/Machine/Mill.md`).  
사용량: 후반까지 **대량 사용** 전제. 후기에는 비료 살포 **자동화** 예정(프로토타입 범위 밖).

**확정 — 교접 하한**

- 비료를 쓴 상태에서 교접하면, 자식 각 스탯은 **일정 캡에 도달하기 전**까지 **부모 평균 미만으로 떨어지지 않음**.
- 즉 캡 미만 구간에서는 `자식스탯 = max(상속결과, 부모스탯평균)` (평균·상속 반올림/클램프 세부는 tofill·구현 시 정리).
- 캡에 도달한 스탯부터는 일반 상속(§5.3)처럼 평균 아래로 내려갈 수 있음.

**확정 — 성장 보너스**

- 비료는 작물 **스탯과 별개**로 **성장 속도 보너스**(필요 틱 감소)를 줌.
- 스탯의 `성장 속도`와 가산·독립. 스탯 만땅이어도 보너스는 따로 붙을 수 있음.

**확정 — 사용 방법 (비료 뿌리개)**

- 플레이어는 **여러 도구**를 쓰며, 화면 **하단 퀵슬롯**에 등록해 전환.
- **첫 비료**를 얻으면 상점에 **비료 뿌리개** 해금. 가격 **0골드**.
- 퀵슬롯에 뿌리개 등록 → **좌클릭으로 도구 선택**.
- 선택 후 칸 위에서 **좌클릭 호버 10틱(0.5초)** 유지 시 해당 칸에 비료 살포.
- **우클릭**으로 살포(호버) **중단**.

효과 지속·칸당 소비량·빈 칸 가능 여부·캡/보너스 수치: `01_System_tofill.md`.

### 5.6 도구 · 퀵슬롯

- **확정**: 하단 **퀵슬롯**. 도구(및 후속 아이템)를 등록해 활성 도구 전환.
- **확정**: 비료 뿌리개는 도구의 하나. 후기 자동화는 같은 “비료 부여” 효과를 기계가 대신 수행.

슬롯 개수·기본 도구 목록: tofill / 후속.

## 6. 티어 · 도감

- Species/변종 발견 → 도감 (후속).
- **프로토타입**: Species **벼만**.

## 7. 위험 · 압박

- **확정**: 작물 **사망/고사 없음** (아직).
- Weed 등도 없음.

---

## 8. 시점 · 밭 · 공간 · 입력

- **확정**: **2D 탑다운**, 밭 **5×5**.
- 칸: 비움 / 작물 / **식물 교접 지지대** / (후기) 기타.
- **확정**: 하단 **퀵슬롯**으로 활성 도구 선택 (§5.6).
- **확정**: 기본 좌클릭 — 심기·수확·지지대 등 (활성 도구에 따라 동작 분기).
- **확정**: 비료 뿌리개 선택 시 — 칸 **좌클릭 호버 10틱(0.5초)** 살포, **우클릭** 중단 (§5.5).
- **확정**: 작물 스탯은 기본 숨김. **우클릭 20틱(1초) 홀드**로 공개 (선물 상자). 교접 자식은 미공개로 시작. 인벤 씨앗으로 심은 작물은 이미 안 상태라 공개.
- `(가정)` 스탯 개봉 우클릭과 뿌리개 중단 우클릭은 **활성 도구/대상**으로 구분. 충돌 시 우선순위 tofill.

---

## 9. 진행 곡선 (도파민 설계)

1. **초반**: 낮은 스탯, 수동 수확, 숫자 오르는 맛.
2. **중반**: 교배·변종.
3. **후반**: 자동화·대량 밭.

프로토타입: 1 + 교배(지지대·상속). 변종 롤은 문서만.

---

## 10. 프로토타입 범위 (확정분)

포함:

- 시간: **1초 = 20틱**, 성장·가공은 틱 기준
- 2D 탑다운, 5×5, 좌클릭 조작
- 스탯 공개: **우클릭 20틱(1초)** (교접 자식=미공개 시작)
- Species **벼**: **성장 속도**, **드랍률** (각 0~5), 단계 0/1/2
- `growTimeTicks = 600 - 80 * 성장속도`
- 시작 씨앗 1개 (성장 0 / 드랍 0), **빈 칸만** 심기
- 수확: 벼(작물)만, **칸의 작물은 남기고 성장 리셋**, 벼 **10골드** 판매, 씨앗 판매 불가
- 드랍률 효과: 미정 (스탯 자체는 유지)
- 시작 골드 **0**
- **식물 교접 지지대**: 시작 10개·소비·**5골드** 구매, 부모≥1, 지지대 칸에서 자식 성장
- **비료**: 교접 하한(캡 전)+스탯 독립 성장 보너스
- **비료 뿌리개**: 첫 비료 시 상점 해금 **0G**, 퀵슬롯, 좌클릭 호버 0.5초 살포 / 우클릭 중단
- 후기: 비료 살포 자동화 (문서만)

제외 (명시):

- 유전자 풀 변종 20% 롤 (규칙만, 미구현)
- 작물 사망, Weed, 환경, **비료 자동화 구현**, 풍부한 도감 UI

나머지: `01_System_tofill.md` 또는 대화로 결정 후 반영.
