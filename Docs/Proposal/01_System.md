# 01. 게임 시스템

## 0. 한 줄 컨셉

Gregtech: New Horizons의 **cropsNH** 루프만 떼어, **교배·스탯·티어 상승이 도파민 보상**이 되는 농사 게임.

레퍼런스: IC2 crops / GTNH cropsNH (교배·육종 루프).  
**차이**: cropsNH처럼 전 작물 공통 G/G/R이 아니라, **작물 종류(Species)마다 스탯 구성이 다름**.

확정 아닌 가정은 `(가정)`. 미결은 `01_System_tofill.md`.

---

## 0.1 시간 단위 (틱)

- **확정**: 게임 내부 시간은 **틱** 기준.
- **확정**: **1초 = 20틱**.
- 성장·기계 가공 등 진행은 틱으로 표기·계산. (필요 시 초 환산은 `/20`)

---

## 1. 핵심 루프

```
심기 → 성장 → (선택) 교배/변종 → 수확 → 스탯 좋은 씨앗 확보 → 재투자
```

도파민 포인트 (목표 체감):

| 순간 | 보상 감각 |
|------|-----------|
| 스탯 상승 | 숫자 올라감 |
| 변종·신종 | 발견·잭팟 |
| 밭 확장·자동화 | 규모 쾌감 |

프로토타입 최소 루프: **심기 → 성장 → 수확 → 씨앗 스탯 확인 → 재파종**.

## 3. 성장

- **확정**: 성장은 **틱**으로 진행 (1초 = 20틱).
- **확정**: **전 작물 기본** — Mature **최저 1200틱(60초) / 최고 200틱(10초)**, 성장 단계 **3** (상세·선형 보간은 `00_CropFormat.md`). Species가 다르면 작물 문서에 명시.
- **확정**: 스탯 범위·수확 수량·판매가는 **Species마다** 작물 문서.
- **확정**: **비료 성장 보너스**는 작물 스탯과 **독립**으로 추가 적용 (§5.5).

`(가정)` 환경(양분·습도·공기)은 프로토타입에서 생략.

## 4. 심기 · 수확 · 씨앗

### 4.1 시작 · 심기

- **확정**: **빈 칸에만** 심기 가능. 씨앗 1개 소비 → 해당 스탯 작물 배치.
- 시작 지급·시작 스탯·씨앗 가격: **해당 Species 문서** (§2.1).

### 4.2 수확

- **확정**: Mature 수확 시 산출물·수량·칸 잔류·판매가는 **해당 Species 문서**.
- Species별 미결: 해당 작물 문서 + `01_System_tofill`.

---

## 5. 교배 · 변종 · 경제

### 5.1 교접 지지대 (프로토타입 포함)

- **확정**: 프로토타입에 **교배 넣음**.
- **확정**: 빈 칸에 **식물 교접 지지대**를 놓으면(소비), 그 칸의 **상·하·좌·우 4칸** 작물이 **부모**.
- **확정**: 부모 **≥ 1**이면 진행.
- **확정**: 자식은 **지지대 칸에서 새 작물로 성장** (스탯 §5.3).
- **확정**: 지지대는 **소비 아이템**. 시작 **10개** 지급. 상점에서 **5골드**에 구매.
- **확정**: 프로토타입에서 교배 가능한 부모 Species는 **벼** (`Docs/Crops/Rice.md`).
- 변종 20% 롤은 §5.2 (프로토타입 미구현).

### 5.2 변종 (유전자 풀) · 신종 씨앗 획득

- 교배 시 **20%** 확률로 부모 Species의 **유전자 풀**에서 결과 등장 (동종 강화 / **다른 Species** / 변종).
- **확정**: 이 변종·풀 롤은 **현재 프로토타입에서 구현하지 않음** (규칙만 문서화).
- 변종 스탯: 부모와 **같은 스탯 키** → 상속. **새 스탯** → **0**.

**확정 — 감자·당근 씨앗 획득 (이중 경로)**

| 경로 | 내용 |
|------|------|
| 1. 변종 풀 | **벼(쌀)** 교배 시 유전자 풀에 **감자·당근** 포함 → 발견형 획득 (`Rice.md`) |
| 2. 상점 구매 | 감자·당근 기본 스탯 씨앗 **구매 가능** (가격·스탯은 각 작물 문서) |

- 구매 = 안정 온램프. 풀 = 교배 도파민(발견). **둘 다 씀** (기계 전용 루트는 쓰지 않음).
- 풀 가중치·등장 형태(씨앗 vs 자식 작물): `01_System_tofill` + `Rice.md`.

**확정 — 콩 씨앗 획득 (교배 전용)**

| 경로 | 내용 |
|------|------|
| 감자+당근 교배 | 부모에 **감자·당근이 함께** 참여한 교배에서 **콩** 등장 (`Bean.md`) |
| 상점 | **판매하지 않음** |
| 벼 풀 | **포함하지 않음** |

- 콩 = 교차 교배 보상. 세부 확률·부모 조건: tofill B01.

### 5.3 상속 공식

```
자식스탯 = 부모스탯평균 + RandomInt(-2, 4)
```

- `부모스탯평균`: 상하좌우 부모(1~4)의 해당 스탯 평균.
- `RandomInt(-2, 4)`: -2 이상 4 이하 정수 균등.
- `(가정)` 결과는 **해당 Species 문서의 스탯 범위**로 클램프.
- 비료가 적용된 교접이면 §5.5 하한 규칙 추가 적용.

### 5.4 경제 (골드)

| 항목 | 가격 |
|------|------|
| 작물·씨앗 (Species) | **해당 작물 문서** (§2.1) |
| 식물 교접 지지대 구매 | **5골드** |
| 비료 뿌리개 (첫 비료 후 해금) | **0골드** |

- **확정**: 시작 골드 **0**.
- **확정**: **씨앗 판매 불가**. 기본 스탯 씨앗 구매 가능 여부·가격은 Species 문서.

### 5.5 비료

출처: Mill이 작물을 가공해 **비료** 생산 (`Docs/Machine/Mill.md`).  
사용량: 후반까지 **대량 사용** 전제. 후기에는 비료 살포 **자동화** 예정(프로토타입 범위 밖).

**확정 — 교접 하한**

- 비료를 쓴 상태에서 교접하면, 자식 각 스탯은 **일정 캡에 도달하기 전**까지 **부모 평균 미만으로 떨어지지 않음**.
- 즉 캡 미만 구간에서는 `자식스탯 = max(상속결과, 부모스탯평균)` (평균·상속 반올림/클램프 세부는 tofill·구현 시 정리).
- 캡에 도달한 스탯부터는 일반 상속(§5.3)처럼 평균 아래로 내려갈 수 있음.

**확정 — 성장 보너스**

- 비료는 작물 **스탯과 별개**로 **성장 속도 보너스**(필요 틱 감소)를 줌.
- 스탯의 `성장 속도`와 가산·독립. 스탯 만땅이어도 보너스는 따로 붙을 수 있음.

**확정 — 사용 방법 (비료 뿌리개)**

- 플레이어는 **여러 도구**를 쓰며, 화면 **하단 퀵슬롯**에 등록해 전환.
- **첫 비료**를 얻으면 상점에 **비료 뿌리개** 해금. 가격 **0골드**.
- 퀵슬롯에 뿌리개 등록 → **좌클릭으로 도구 선택**.
- 선택 후 칸 위에서 **좌클릭 호버 10틱(0.5초)** 유지 시 해당 칸에 비료 살포.
- **우클릭**으로 살포(호버) **중단**.

효과 지속·칸당 소비량·빈 칸 가능 여부·캡/보너스 수치: `01_System_tofill.md`.

### 5.6 도구 · 퀵슬롯 · 인벤토리

- **확정**: 하단 **퀵슬롯**.

| 슬롯 | 내용 |
|------|------|
| 1 | **맨손** — 수확 · 기계 조작. **우클릭(짧게)** → 땅 메뉴 |
| 2 | **배치** — 보유 건물 목록 → **그리드 칸**에 배치 |
| 3~ | **획득 도구** (비료 뿌리개 등) |

**맨손 우클릭 — 땅 메뉴**

| 항목 | 동작 |
|------|------|
| 씨앗 심기 | 씨앗 선택지 → 해당 칸에 심기 (빈 칸) |
| 교접 지지대 | 해당 칸에 지지대 설치 |
| 파내기 | 해당 칸 **작물 제거** (수확물·씨앗 반환 없음) |

- **확정**: 건물(Mill 등)은 **그리드 단위** 배치 (프로토 Mill = 1×1).
- **확정**: **인벤토리** — 중앙 하단 트리거. 씨앗·작물·지지대·비료·건물·도구 등 **전부 확인**.
- 씨앗 목록은 `성장 N / 드랍 N ×수량`처럼 직관 표기. 지지대 개수는 씨앗 UI에 붙이지 않음.
- `(가정)` 맨손 우클릭 **짧게**=땅 메뉴, **길게(20틱)**=스탯 개봉. 메뉴 클릭 임계 ≈5틱.

### 5.7 상점 카테고리

- **확정**: 상점 UI는 **구매 / 판매** 카테고리로 나눔.
- 구매: Species 씨앗(문서 기준)·지지대·Mill·(해금 시) 뿌리개 등.
- 판매: Species 산출 작물(문서 기준). 씨앗 판매 불가.

## 8. 시점 · 밭 · 공간 · 입력

- **확정**: **2D 탑다운**, 밭 **5×5**.
- 칸: 비움 / 작물 / **식물 교접 지지대** / (후기) 기타.
- **확정**: 퀵슬롯 **맨손 / 배치 / 획득도구…**, 중앙하단 **인벤** (§5.6). 상점 **구매|판매** (§5.7).
- **확정**: 맨손 좌클릭=수확·기계. 맨손 우클릭 짧게=땅 메뉴(심기·교접·파내기). 배치=그리드 건물.
- **확정**: 뿌리개 — 칸 **좌클릭 호버 10틱(0.5초)** 살포, **우클릭** 중단 (§5.5).
- **확정**: 작물 스탯 기본 숨김. **우클릭 홀드 20틱(1초)** 공개. 교접 자식 미공개 시작.
- `(가정)` 맨손: 우클릭 짧게=땅 메뉴 / 길게=스탯. 뿌리개 살포 중 우클릭=중단.

## 9. 진행 곡선 (도파민 설계)

1. **초반**: 낮은 스탯, 수동 수확, 숫자 오르는 맛.
2. **중반**: 교배·변종.
3. **후반**: 자동화·대량 밭.

프로토타입: 1 + 교배(지지대·상속). 변종 롤은 문서만.

---

## 10. 프로토타입 범위 (확정분)

포함:

- 시간: **1초 = 20틱**, 성장·가공은 틱 기준
- 2D 탑다운, 5×5, 좌클릭 조작
- 스탯 공개: **우클릭 20틱(1초)** (교접 자식=미공개 시작)
- Species: §2.1 작물 문서 (`Rice.md` / `Potato.md`)
- 전 작물 기본: Mature 60초→10초, 단계 3 (`00_CropFormat.md`)
- **빈 칸만** 심기, 씨앗 판매 불가
- 시작 골드 **0**
- **식물 교접 지지대**: 시작 10개·소비·**5골드** 구매, 부모≥1, 지지대 칸에서 자식 성장. 프로토 부모 Species → `Rice.md`
- **비료**: 교접 하한(캡 전)+스탯 독립 성장 보너스
- 퀵슬롯: **맨손 / 배치 / 획득도구**
- 맨손 우클릭: **땅 메뉴**(심기·교접·파내기) / 길게 스탯 개봉
- **파내기**: 작물 제거, 반환 없음
- 인벤토리: 중앙 하단 트리거, 보유물 전체 확인
- 상점: **구매 | 판매** 카테고리
- **비료 뿌리개**: 첫 비료 후 해금 **0G**, 획득 도구 슬롯, 호버 0.5초 살포
- 후기: 비료 살포 자동화 (문서만)

제외 (명시):

- 유전자 풀 변종 20% 롤 (규칙만, 미구현)
- 작물 사망, Weed, 환경, **비료 자동화 구현**, 풍부한 도감 UI

나머지: `01_System_tofill.md` 또는 대화로 결정 후 반영.
