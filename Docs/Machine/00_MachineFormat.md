# 기계 문서 양식

`Docs/Machine/` 아래 개별 기계 `.md`는 이 양식을 따른다.

## 시간 단위

- 게임 시간: **틱**. **1초 = 20틱** (`01_System.md` §0.1).
- 레시피 **가공 시간**은 틱으로 적는다. (예: 100틱 = 5초)

---

## 기계 이름

| 항목 | 내용 |
|------|------|
| 구매 방식 | （예: 상점 구매 / 제작 / 퀘스트 보상） |
| 구매 가격 | （골드 또는 재료） |
| 차지하는 칸 수 | （예: 1×1, 2×1） |
| 기능 설명 | （한 줄~짧은 문단） |

### 레시피

기계가 여러 레시피를 가지면 `#### 레시피 이름`을 반복한다.

#### 레시피 이름

| 구분 | 내용 |
|------|------|
| 인풋 | （소비 아이템·수량） |
| 아웃풋 | （산출 아이템·수량） |
| 가공 시간 | （틱. 1초 = 20틱） |
